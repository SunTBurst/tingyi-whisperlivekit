## 在自己的环境运行测试

先完成 Setup，获取固定上游并安装依赖，然后安装独立测试工具：

```powershell
uv pip install --python .venv\Scripts\python.exe pytest
.venv\Scripts\python.exe -m pytest tests -q
```

没有测试音频或模型时，不应把跳过项当作实际推理已通过。上述音频尾块测试可能随时间起点间歇失败；请保留失败结果用于复现。测试主体使用合成与临时材料；真实采音或模型质量应按自己的设备另行验收。
