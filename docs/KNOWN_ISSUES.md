# 使用边界与已知问题

- 当前发布是 Windows 源码版本，不附带安装环境、模型或打包 EXE。原维护环境的完整回归通过401项测试及22个子测试；公开安装入口新增的检查另行记录。不同电脑的首次依赖安装与实际设备会议质量需要自行验收。
- 默认听写不依赖 LM Studio。Whisper 负责语音转文字；中文或其他任意目标文本翻译需要相应翻译后端。Whisper 自带的直接翻译目标为英语，不能代替任意目标语言翻译。
- LocalAgreement + NLLB 实时翻译需要明确听写语言。自动语言与翻译的无效组合会被阻止。不要把支持语言清单理解成各种口音和专业术语均准确。
- 说话人分离是声音分组；真实姓名和跨流段关联由用户确认。暂停、语言或模型切换可能建立新分组。不是声纹身份认证。
- 实时翻译、问答与摘要质量依赖模型。本机2B文本模型曾漏掉明确行动项，完整实时翻译检查也未全部通过。AI结果须核对，默认 NLLB 与可选 LM Studio 分开处理。
- 两小时合成数据压力测试和加速音频输入不等于两小时真实 Teams/Zoom 墙钟会议。设备热插拔、蓝牙掉线及所有可选后端尚未全面验收。
- 已知音频尾部混音浮点边界：在特定时间起点与长缺口下可能额外生成一个10毫秒全零块。`tests/test_audio.py` 的既有测试会间歇揭露它；固定起点 `31361.835435589037` 可复现。此公开版本保留原算法和原断言，未通过放宽测试掩盖问题。
- 会议恢复只恢复已保存文字；无法恢复丢失的声音和未保存字幕。记录的 JSON 与 SQLite 应一并备份。
- 主动接入远程 ASR 或文本模型服务时，声音或字幕会按所选端点传输。本地模式与远程端点的隐私边界不同。
- NLLB权重有非商业使用条件；应用代码的 GPL 许可不改变模型许可。
